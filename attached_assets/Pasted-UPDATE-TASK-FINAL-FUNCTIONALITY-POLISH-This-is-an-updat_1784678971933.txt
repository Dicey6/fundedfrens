5. Referral Withdrawals

Add a new feature.

Users who have earned referral commissions should be able to request a withdrawal.

On the Referrals page:

Show a new button:

Request Withdrawal

Only show the button when the user has available referral earnings.

Before allowing submission:

Check whether a payout wallet exists.

Important:

Users who purchased a challenge already paid using a wallet.

That payment wallet should automatically become their default payout wallet unless they later change it manually.

If no payout wallet exists:

Prompt the user to add one first.

If one exists:

Allow the withdrawal request.

Create a pending withdrawal request containing:

* User ID
* Wallet Address
* Withdrawal Amount
* Timestamp
* Status = Pending

Administrators will review and approve these manually.

Do not automatically send funds.

6. Treasury Wallet Rotation

The treasury wallet should no longer always be the same address.

Support multiple treasury wallets.

These wallets will be supplied through the environment variables.

Example:

TREASURY_WALLETS=wallet1,wallet2,wallet3,wallet4,…

When a user creates an order:

* Randomly select one treasury wallet.
* Store that selected wallet on the order.
* Display only that wallet to the user.

Payment verification must verify against the wallet assigned to that specific order.

Never randomly change the wallet after an order has been created.
